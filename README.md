# \# The Reading Room

# 

# A small static catalogue for keeping track of books on a shelf. Titles can be

# searched by name or author, and new ones can be accessioned through a short form.

# Anything added is held in the browser, so the shelf survives a refresh.

# 

# \*\*Live site:\*\* https://is-project-2026.github.io/library-catalogue-164926/

# 

# \## What it does

# 

# \- Lists catalogue entries as index cards showing title, author and year.

# \- Filters the shelf live as you type, matching on either title or author.

# \- Accepts new titles through an accession form, with a warning if the title or

# &#x20; author is left blank. A missing year is recorded as `n.d.`.

# \- Stores additions in `localStorage` so they persist between visits.

# 

# \## Technologies

# 

# | Technology | Used for |

# |---|---|

# | HTML5 | Page structure and semantic sections |

# | CSS3 | Layout, typography and the index-card styling |

# | JavaScript (ES5) | Rendering, search filtering and form handling |

# | Web Storage API | Persisting accessioned titles in the browser |

# | Git \& GitHub | Version control, issue tracking and pull request workflow |

# | GitHub Pages | Hosting the deployed site |
